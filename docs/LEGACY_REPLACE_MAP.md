# 历史替换词典存档（初版 replace_map.py）

> 存档日期：2026-11-22  
> 来源：`git show 7179354:locales/zh-CN/replace_map.py`（项目首个提交）  
> 用途：仅作历史审计参考，**不会被任何构建或运行流程加载**。

## 为什么保留这份存档

初版替换词典（`REPL`）是在早期字库容量不足时引入的：当时大量汉字无法进入
游戏字库，只能把译文里的难字词替换成字库内已有的近义词。典型例子包括
`锯斧→铁斧`、`独角兽→灵角兽`、`钓竿→钓具`、`裂缝→破口`、`兄弟→手足`、
`期待→巴望`、`遵命→得令` 等。

现在字库已扩容到 **2304/2847 格**（`cmap.json`），这些替换不再有容量收益；
而且很多替换并非同义词，已经造成实际语义错误（例如把 `Saw Axe` 写成「铁斧」、
把 `fissure` 写成「破口」、把 `Executor` 写成「照办者」）。因此：

- **不要重新套用这份词典**；
- 新的译名/术语请直接修改 `locales/zh-CN/text_v2.csv`、
  `locales/zh-CN/ml_zh_fields.json` 和 DLC 译表；
- 当前仍在使用的 16 条替换见 `locales/zh-CN/replace_map.py`；
- 历史条目的清理记录见 `docs/PACKAGE_LEDGER.md` 的 Z28/Z29 条目与
  `docs/PITFALLS.md` §47、§49；**逐条进度与待评估清单见本文
  「清理进度与后续评估」**。
