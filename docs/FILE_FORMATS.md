# 1. S2AR 归档（`.s2a`）

**用途：** 游戏资源归档（文本、图集、脚本等）。
**平台：** Windows PC。
**状态：** 已验证（解析 + `pack()` 往返一致）。
**已知文件：** `res/LANG_JA.s2a`、`res/LANG_EN.s2a`、`res/cscv.s2a`、`res/texture.s2a`、
`res/mapdata.s2a`、`res/BGM.s2a`、`res/SE.s2a`、`res/MOV.s2a`、`res/GalleryTex.s2a`、`res/p2a.s2a`、
`DLC01/*.s2a`。
**字节序：** 小端。
**编码：** 归档层无编码；blob 内容自定（文本为 CP932）。
**压缩：** 无。**加密：** 无。

## 1.1 结构

| 偏移 | 大小 | 类型 | 含义 | 状态 |
|---|---:|---|---|---|
| 0x00 | 4 | bytes | magic `S2AR` | 已验证 |
| 0x04 | 4 | u32 | 条目数 `count` | 已验证 |
| 0x08 | 8×count | Entry[count] | 条目表 | 已验证 |
| 0x08+8·count | ... | bytes | blob 数据区（顺序拼接） | 已验证 |

**Entry（8 字节）：**

| 偏移 | 大小 | 类型 | 含义 | 状态 |
|---|---:|---|---|---|
| 0x00 | 4 | u32 | 条目 hash（键） | 已验证 |
| 0x04 | 4 | u32 | blob 字节数 `size` | 已验证 |

**关键点：**

- **[已验证]** 条目**没有显式 offset 字段**；blob i 的文件偏移由 size 前缀和**隐式累加**得到
  （`data_start = 8 + 8·count`；`off(i) = data_start + Σ_{k<i} size[k]`）。
- **[高置信]** 无对齐、无 padding；官方注释称条目按 hash 升序，但代码不强制。
- **[已验证]** 归档内文件**只按 32 位 hash 寻址，没有文件名**。
- **[已验证]** `hash_map()` 返回 `{hash: index}`；**重复 hash 会被 dict 折叠**（后者覆盖）。
- **[已验证]** `pack(archive_path, entries, blobs)`：重算 `size=len(blob)`，保留传入的 hash 与顺序，
  **不排序、不对齐、不校验、不去重**；输出 = `S2AR` + u32(count) + 条目表 + blob 顺序拼接。
  => 相同顺序 + 相同内容 => **逐字节等于原文件**（本项目据此原地重写并保持格式一致）。

**未解：** 条目 hash 算法未知（16 哈希 × 5 编码 × 5 前缀全 0 命中，疑似自定义/带盐）——
无法凭文件名合成新条目的 hash。

**工具：** `_work/s2a.py`。

# 2. CSCV blob

**用途：** 游戏内定长记录表（文本、数据、脚本、字形字符表）。
**状态：** 头部/记录布局已验证。
**编码：** 文本字段 CP932，`0x00` 终止。
**字节序：** 小端。

## 2.1 头（16 字节）

| 偏移 | 大小 | 类型 | 含义 | 状态 |
|---|---:|---|---|---|
| 0x00 | 4 | bytes | magic `CSCV` | 已验证 |
| 0x04 | 4 | u32 | **stride**（每条记录字节数） | 已验证 |
| 0x08 | 4 | u32 | **count**（记录条数） | 已验证 |
| 0x0C | 4 | u32 | 常量 `0xFFFFFFFF` | 高置信 |

## 2.2 记录布局

- **[已验证]** 记录 i 位于 `[16 + i·stride, 16 + (i+1)·stride)`；blob 总长 = `16 + stride·count`。
- **[高置信]** 字段位于记录内固定偏移 `pos`；文本以 `0x00` 终止，末尾 `0x00` 填充到记录尾。
- **[高置信]** 槽容量 `cap` = 同记录内**下一个被占用字段的起点 − 本字段起点**（无后继则到记录末）；
  写入时须留 1 字节 `0x00`（`len(enc) <= cap-1`）。
- **[高置信]** 名字/值字段常带 **4 字节 `0xFF` 前缀**（`FF FF FF FF`），CP932 解码为 `\uf8f3…`；
  定位时须剥离并把 `off/pos` 前移。

**已知 stride 家族与字段偏移（示例）：**

| stride | 字段偏移 pos 示例 | 说明 | 状态 |
|---|---|---|---|
| 424 | 24 / 92 / 124 / 260 / 292 | 脚本标记 / 短名 / 名字 / 命令 / 对话（槽长 132） | 高置信 |
| 292 | 96 / 160 / 224 | 说话人 / 对话两行 | 高置信 |
| 580 | 4 / 36 / 68 / 372 | 章节标题表（章节名 / 称号章节名 / 世界编号 / 大陆名） | 已验证（用于补丁） |
| 1116 | 104 / 136 / 140 | 村落表（地名 / 关卡编号 / 编号） | 已验证（用于补丁） |
| 168 | 0 / 36 | 系统/战斗消息表（key / 值槽） | 已验证（用于补丁） |
| 268 / 376 | 4 / 168·204·236、0 / 32 / 168 / 292 | 装备表 / 技能表 | 已验证（用于补丁） |

未知字段保持未知；不要臆测字段含义。

**工具：** `_work/s2a.py`、`_work/dlce_lib.py`、`_work/probe_*.py`。

# 3. 字形字符表 blob

**用途：** index -> CP932 字符码 的映射表（用于图集取字）。
**状态：** 已验证。
**定位：** `res/cscv.s2a` 中 s2a 条目 hash = **`0xCCCEDC89`**（`TBL_HASH`）；实测落于 blob836。

| 偏移 | 大小 | 类型 | 含义 | 状态 |
|---|---:|---|---|---|
| 0x00 | 4 | bytes | magic `CSCV` | 已验证 |
| 0x04 | 4 | u32 | 观测 32，含义未知 | 未验证 |
| 0x08 | 4 | u32 | **count / 16** | 已验证 |
| 0x0C | 4 | u32 | `0xFFFFFFFF` | 高置信 |
| 0x10 | 2·N | u16[] | 第 i 项在 `0x10 + 2·i`，小端 u16 = CP932 码值 | 已验证 |

- **[已验证]** 项数 `N = (len(blob)-16)/2`；头 `[8]` 决定引擎使用的项数上限（`[8]·16 = N`）。
- 原版：`[8]=89` -> 1424 项 / 2864 字节；扩容后：`[8]=256` -> 4096 项 / 8208 字节。
- 特殊项：`1408 = 0x4445`（'E','D' 打包，疑似结束标记）；`0x0000` = 空槽。
- index 0-255 条目不可删（删了闪退）。

**工具：** `build_cn.py: parse_entries()`。

# 4. 字形图集（texture.s2a 内嵌 BMP）

**用途：** 字形位图。**状态：** 已验证。
**定位 hash：** 图集 B = `0x45781F74`；图集 A = `0x52B69FD4`。
**内嵌格式：** 8bpp 调色板 BMP。

| 项 | 值 |
|---|---|
| 格尺寸 | 16×16 |
| 列数 | 32 |
| 扩容后尺寸 | 512×1024（两张） |
| 页号 | `62 + ((i>>10) & 1)`（62=B, 63=A） |
| 取格 | `x=((i>>11)<<4)+(i%16)`；`U=(x&31)*16`；`V=((i>>4)&63)*16` |

- 图集 A 的 `x∈[0,256) y∈[96,224)` 为硬编码 ASCII 路径占用带。
- 调色板：A 的 idx19/20 = 灰/近黑；B 的 idx19/20 = 青绿（两页调色板不同）。
- `idx0` 为透明键。

# 5. LANG 文本槽模型

**用途：** `LANG_JA/LANG_EN` 文本存储。**状态：** 已验证。

- 文本在 CSCV 记录内呈**定长槽**；`slot_bytes` 为字节上限，`0x00` 终止，其后 `0x00` 填充。
- **多行字段**：`[行1]\x0A[行2]…\x00 + 0 填充`，属**同一记录内的一个字段**；
  `text_v2.csv` 只登记第 1 行，整段译文在 `ml_zh_fields.json`。
- 容量：`max_cn = slot_bytes/2`；整字段容量由"`field_end()` 到下一非零字节 − off − 1"现算。

# 6. `hm2zh_patch.bin`（运行时补丁数据）

**用途：** 供 `dinput8.dll` 代理 DLL 在内存中施加 exe 等价补丁。
**状态：** 已验证（由 `gen_patch_bin.js` 生成并自测）。
**字节序：** 小端。

```text
Header 16B: 'H2ZP' | u16 ver=1 | u16 flags=0 | u32 imagebase=0x400000 | u32 count
Type1: u8 type=1 | u8 len | u8 window=0 | u8 rsv | u32 va | u32 expect=0 | u32 delta=0 | orig[len] | new[len]
Type2: u8 type=2 | u8 len=0 | u8 window | u8 rsv | u32 va | u32 expect | u32 delta（相对 atbl 基址）
```

- Type1：在 `va` 处逐字节校验 `orig` 后写入 `new`。
- Type2：在 `va` 起 `window` 字节内搜索 u32 `expect`，替换为 `atbl_base + delta`。
- 实测：414 字节 / 18 条（type1=10, type2=8），作用域 VA `0x004D861F..0x004D8E3B`。

**工具：** `_work/proxydll/main.c`、`gen_patch_bin.js`。

# 7. `name_ledger.json`（名字批次账本）

**用途：** 名字类批次逐槽记账与回滚。**状态：** 已验证。

```json
{ "batches": [ { "id": "称号名-G1", "class": "称号名", "ts": "20260918_232650",
  "note": "...", "edits": [ { "f": "LANG_JA", "b": 666, "off": 2648,
  "old": "8e9e...", "new": "88cd..." } ] } ] }
```

- `f` = 文件 tag（`LANG_JA`/`LANG_EN`/`cscv`/`DLC01_LANG_JA`/`DLC01_LANG_EN`）；
  `b` = blob 索引；`off` = 原版起始字节偏移；`old`/`new` = 原版/写入 run 的 hex。
- 回滚 = 把 `old` 写回 `off`，`[len(old), max(len(old),len(new)))` 清零。
- 现有 24 批 / 44,129 槽。

**工具：** `_work/nmledger.py`、`_work/t140_name_revert.py`。
