## 4. 执行规范（后续批次）

1. **先同步全部副本，再构建**：敌名/道具名/称号按 `(blob, pos)` 找齐 `b54/b555/b734/b748/b777/b1008/b1034`、
   `b147/b357/b736/b998/b713/b379/b758`、`b931` 等副本；不得只改可见行。
2. **机制名保护**：构建会重算名字哈希操作数；`validate_build` 必须 **error 0**。
   `Hero Cloth` 与 `Hero Cross` 共用日文串，需单独做小包确认。
3. **字节复核**：用上一版产物取旧串，在新产物中计数应为 0；新串数量应等于预期副本数。
4. **实机验证**：图鉴、Boss 战说话人、商店/装备列表、宝箱标签、称号解锁。
5. **文档同步**：`术语表.md`、`PACKAGE_LEDGER.md`、本文件、`docs/TODO.md`。
