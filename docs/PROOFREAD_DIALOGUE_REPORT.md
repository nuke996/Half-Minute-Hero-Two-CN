## 4. 系统性问题二：英文二次转译失真

这是本轮数量最多、也最影响剧情理解的一类。典型模式：

- **语义反转**：肯定变否定、主动变被动、主语/宾语对调（「我忘了」→「你把我忘了」）。
- **专名/对象被换掉**：`おやじ` 被英文当成人名 Guy → 译成「盖伊」；`アテナ` 被英文代词化 → 译成「你」。
- **信息凭空增删**：英文稿的舞台提示、解释性短语被译进中文（`*sigh*`、`I see`→「我看见了」）。
- **语气改写**：敬称、大小姐口吻、粗鲁口吻被抹平或改成另一种人物。
