# 术语表（简体中文）

本表供译者校对、统一用字时参考。所有「现用译名」均取自当前 `locales/zh-CN/text_v2.csv` 与 `locales/zh-CN/dlc/`，并已随本版打包进 `dist/`。

- 原文以日文为准，英文版仅作参考。
- 【已统一】表示当前构建中该词只有一种写法（或已按语境刻意区分）。
- 【待确认】表示仍存在多种译名，或现有译名疑似有误，请不要自行扩大使用，先与负责人确认。
- 【DLC】表示该译名只用于 DLC01，与主线可能是不同事物，**不要合并**。

> 范围说明：本表收录专名、神明/人物、地点、组织、怪物、BOSS、关键道具装备、职业/技能/阵形与系统 UI 词。通用装备（铁剑、皮甲、草药一类）按常规译法处理，不逐条列出。

## 13. 技术约束（改词前必读）

1. **构建同时写 `LANG_JA.s2a` 与 `LANG_EN.s2a`**，槽位上限取两者较小值。英文槽位短时，中文只能用短形式：
   - `Omega`（5 字节）→ 最多 2 个汉字，`欧米伽` 超长时回退 `欧米`。
   - `Jelly`（5 字节）→ 最多 2 个汉字，`果冻怪` 超长时回退 `果冻`。
   若确实需要完整写法，应向负责人申请调整槽位策略，不要手改二进制。
2. **`cscv.s2a` 的键名/脚本层保持原版 CP932**，只翻译 `LANG` 显示层。按名字查找的键（技能名、装备名、职业名、城/关卡名等）必须与原版保持一致，否则会出现「道具只有文字、没有效果」「章节开始装备消失」等问题。
3. **占位符与控制码不可改动**：`<RGN_NAME__>`、`<YUSHA_NAME>`、`<ADH1P_NAME>`、`{0}`、`%s`、`\n`、`¶`、`▼`、`♪` 等必须原样保留，数量与位置不变。
4. **改词流程**：修改 `locales/zh-CN/text_v2.csv` 的 `zh_new` 列（DLC 改 `locales/zh-CN/dlc/`），再运行：

   ```text
   .\.venv\Scripts\python.exe tools\build.py package
   ```

   构建必须显示「溢出 0」。`work/original` 是只读母本，不要在打包前改动它。
5. **DLC 与主线分开**：DLC01 的文本在 `locales/zh-CN/dlc/zh_01.tsv` ～ `zh_06.tsv` 与 `zh_07.json`（`zh_07.tsv` 只是索引，正文以 JSON 为准）。同名日文在 DLC 与主线可能指不同事物，已确认的差异见 §11、§12。
